# SpacePet · 星际宠物嘟嘟

面向乡村留守儿童的科普陪伴网页。孩子唤醒来自外星的宠物「嘟嘟」并给它起名字，嘟嘟每次分享自己在人类家庭和地球上的新发现，用提问和猜谜的方式，陪孩子一起认识物理、化学、生物、天文和地理。

**打开即玩，不需要安装、不需要注册、不需要配置 API Key。** 默认使用内置的 600 道科学题和本地聊天回复，断网也能玩；如果本地额外配置了 DeepSeek Key，则会自动切换为 AI 生成内容。

## 项目背景

乡村留守儿童往往缺少持续的陪伴和高质量的科普引导。SpacePet 把「会说话的小伙伴」和「科学小问答」结合在一起：

- **陪伴感**：嘟嘟不是问答机器人，而是一个寄宿在好朋友家、每天自己出门探索的外星宠物。它用「你」来称呼孩子，不叫「主人」、不反复喊名字，努力像一个真正的朋友。
- **科普性**：每天 10 个科学分享，覆盖物理、化学、生物、天文、地理五个学科，每个学科 2 道，共 600 道内置题目。
- **难度适宜**：题目用小学高年级能读懂的语言编写，知识点以初中水平为上限，不出现超纲公式和术语；新增题目也都配有嘟嘟的讲解，答错时会先讲明白再让孩子重试。
- **每天换新**：题目按日期选取。同一天打开永远是同一套 10 道，第二天自动换成新的 10 道；每个学科 120 道题，约 60 天内不重复，一轮结束后重新打乱复习。
- **低门槛**：不需要安装 App，手机浏览器打开就能玩；支持中文语音朗读，降低识字量不足的孩子的使用门槛。
- **可离线**：不依赖网络和 API，内置题库与本地聊天回复，打开即可完整玩一轮。
- **可持续**：答错的题目进入「嘟嘟的错题本」，方便复习；名字、错题和连续打卡天数保存在本地，不上传服务器。

## 玩法

1. **唤醒与起名**：打开页面点击「点击唤醒星际宠物」，首次使用时输入自己的名字，嘟嘟会记住这位好朋友。
2. **每日挑战**：界面显示「今日挑战 n/10」，每天固定 10 关（5 个学科 × 2 题）。每一关嘟嘟先讲一段自己的见闻，再提出一个三选一的问题。
3. **答题与亲密度**：答对后亲密度进度条增长、进入下一关；答错或点「我不知道」时，嘟嘟会先把这道题背后的科学道理讲清楚，再重新给出选项，让孩子带着理解再试一次，同时把题目记入错题本。
4. **神奇小拓展**：部分题目答对后还有一个「猜猜看」小拓展问题，揭晓答案并鼓励孩子自己动手观察。
5. **错题本**：点击右上角「📕 错题本」随时查看错题、正确答案和嘟嘟的解析。
6. **连续打卡**：完成当天 10 题后记录连续天数，第二天再来会显示「🔥 连续 N 天」。
7. **自由聊天**：完成 10 个分享后，底部会解锁聊天输入框，可以自由和嘟嘟聊天（离线模式下为本地回复）。
8. **重置**：右上角「🔄 重置」清空名字、错题和进度，重新开始。
9. **语音朗读**：嘟嘟说的话会尝试用浏览器语音合成朗读，并自动过滤 emoji 和语气词；如果设备或微信内置浏览器不支持语音，会自动跳过朗读，不影响游戏进行。

## 每日出题机制

- 使用本地日期作为随机种子，同一天多次打开得到同一套题，不同日期自动换题。
- 每个学科每天取 2 道。学科内部先把 120 道题按周期打乱，再按天取连续两题，保证一个 60 天周期内不重复。
- 周期结束后会用新种子重新打乱，进入下一轮复习，避免长期只看到固定顺序。
- 选项顺序每天也会打乱并重新标注 A/B/C，防止孩子记住「答案总在 A」。

> **关于「每天推送」**：这是一个纯静态网页，没有服务器，无法在微信里主动发消息提醒。目前的实现是「按日期自动换题」——孩子每天打开都是新的 10 道。若需要真正的微信推送提醒，需要额外接入微信公众号或后端的定时消息服务，不能仅靠静态页面完成。

## 技术栈

| 技术 | 说明 |
| --- | --- |
| 原生 HTML / CSS / JavaScript | 无框架、无构建步骤 |
| 内置科学题库 | 600 道题，物理 / 化学 / 生物 / 天文 / 地理各 120 道，含解析；部分题目带拓展题 |
| [DeepSeek Chat API](https://api.deepseek.com)（可选） | 本地配置 Key 后，可通过 `fetch` 调用 `deepseek-chat` 模型生成每日分享、题目和自由对话 |
| Web Speech API (`speechSynthesis`) | 中文 TTS 朗读，优先选择 Xiaoxiao / Yunxi 等中文音色；不支持时自动跳过 |
| localStorage | 保存孩子名字、错题本和连续打卡（键：`dudu_student_name`、`dudu_wrong_book`、`dudu_last_done`、`dudu_streak`），读写失败时自动降级 |
| CSS Animations | 宠物悬浮、眨眼、气泡弹出、按钮脉冲等动效 |

### 实现要点

- **离线优先**：扩展题库在 `questions.js` 中，使用紧凑数组格式；`index.html` 启动时合并、校验并去重。没有 Key 时直接按日期抽题；有 Key 但网络异常、返回格式错误时，也会自动回退到内置题目。
- **AI 模式可选**：只有检测到有效的 `config.js` 配置时才启用 AI，公开部署时不带 `config.js`，访问者无需也无法接触 Key。
- **Prompt 契约**：系统提示词要求模型严格返回单行 JSON（场景、题干、三个选项、正确答案、反馈、解析、拓展题），前端解析后渲染，并做字段完整性校验。
- **角色语气约束**：Prompt 约束 + 前端双重过滤「哈哈」「主人」等词，避免模型出戏或使用不当称呼。
- **移动端适配**：使用 `100dvh`、安全区 padding、可伸缩聊天区和可滚动选项区，适配手机屏幕与微信内置浏览器。
- **语音兜底**：检测不到可用中文语音时直接跳过朗读；朗读带超时保护，避免微信 WebView 不触发 `onend` 导致页面卡住。
- **存储兜底**：`localStorage` 在隐私模式或部分 WebView 中可能不可用，读写均做了异常捕获。

## 快速开始

### 方式一：直接打开（默认离线模式）

双击 `index.html`，或在项目目录启动一个本地服务器：

```bash
python -m http.server 8000
```

然后访问 <http://localhost:8000>。

不需要任何配置，打开即可玩。

### 方式二：启用 AI 模式（可选）

1. 准备一个 DeepSeek API Key（在 [DeepSeek 开放平台](https://platform.deepseek.com) 申请）。
2. 复制示例配置并填入 Key：

   ```bash
   cp config.example.js config.js
   ```

   ```js
   // config.js
   window.DUDU_CONFIG = {
       DEEPSEEK_API_KEY: "sk-你的Key"
   };
   ```

3. 重新打开页面。检测到有效 Key 后，嘟嘟会自动改用 AI 生成内容；网络异常时回退到内置题库。

> ⚠️ `config.js` 已被 `.gitignore` 忽略，只适合自己本地使用。**不要把带 Key 的 `config.js` 上传到任何公开托管、网盘或代码仓库。**

## 发给别人使用

先构建单文件版本（把题库内联进 HTML，并移除 `config.js` 引用，确保不包含任何 Key）：

```bash
node build-standalone.js
```

生成的 `dist/SpacePet.html` 就是可以分发的完整单文件。然后：

1. 只上传 `dist/SpacePet.html` 到任意静态托管服务：
   - 国内访问、微信内打开：花生壳 Drop、阿里云 OSS、腾讯云 COS 等；
   - 海外：Cloudflare Pages、Netlify、GitHub Pages 等（国内访问可能较慢）。
2. 获得 HTTPS 链接后，直接通过微信发给对方。对方在手机上点开链接即可游玩，无需下载、登录或配置任何东西。
3. 也可以把 `dist/SpacePet.html` 作为文件直接发送；对方用手机浏览器打开即可（部分微信版本不能直接打开本地 HTML 文件，推荐使用链接）。
4. 直接分享源码目录时，请确保不包含 `config.js`。

## 安全与隐私

- **公开部署不带 Key**：默认离线模式不读取、不发送任何 Key。`build-standalone.js` 生成的分发版不包含 `config.js` 引用。
- **API Key 不进仓库**：Key 只保存在本地 `config.js` 中，该文件已被 `.gitignore` 忽略。请勿把 Key 写回 `index.html` 或任何会被提交的文件。
- **纯前端的固有限制**：如果启用 AI 模式并把页面公开部署，任何能打开页面的人都能在网络请求中看到 Key。**公开部署请保持离线模式，或改用后端 / Serverless 函数代理请求。**
- **Key 一旦泄露立即轮换**：如果 Key 曾经出现在提交记录、公开仓库或聊天记录中，请到 DeepSeek 控制台删除并重新生成。
- **儿童隐私**：孩子输入的名字、错题本和打卡记录只保存在本机 `localStorage`，不会上传；离线模式下所有内容都在本机运行。启用 AI 模式时，对话内容会发送给 DeepSeek 用于生成回复，建议由家长或老师告知并监护。

## 浏览器兼容性

- Chrome / Edge / Android 浏览器（推荐）：页面与答题正常，中文语音合成可用。
- 微信内置浏览器：页面与答题正常；语音合成可能不可用，会自动跳过朗读。
- Safari（iOS）：语音合成可用，需要用户点击后才能播放；音色与 Windows 不同。
- Firefox：语音合成依赖系统语音包，可能没有中文音色，页面会自动跳过朗读。
- 需要支持 ES6、`localStorage`，不支持 IE。
