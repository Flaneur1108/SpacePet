# SpacePet · 星际宠物嘟嘟

一个给小学生使用的 AI 科学陪伴网页。孩子输入自己的名字或小名、选择年级后，会和来自闪闪星的外星宠物「嘟嘟」一起探索物理、化学、生物、天文和地理。

题目没有固定总数，也没有“今天只能做 10 题”的限制。每次打开会结合日期、学生、已做过的题和最近学科生成新的练习；答完一题马上就有解释、鼓励和小知识，不需要等网络。

## 适合课堂和家庭的几个特点

- **每个孩子有自己的档案**：同一台电脑可以给多位同学使用，名字、年级、星星、连续天数、错题本互不混淆。
- **无限练习，不设通关上限**：本地星际题库 + AI 出题混合工作。AI 没连上、网络慢或接口忙时，仍然能立刻出题。
- **每天不一样**：日期种子、学生身份、每日主题、已见题目签名和最近学科共同参与选题，尽量避免重复。
- **即时反馈**：题目自带提示、正确答案、解释和小知识。第一次答错会鼓励再试，第二次答错会讲解原理，不会把孩子卡住。
- **有秩序的错题宝盒**：按学科分组、按“待复习 / 已掌握”筛选；可以原地重做；同一道错题累计答对 3 次后，才会解锁“移出错题本”。
- **适合孩子的操作**：大按钮、三选一、键盘 1/2/3、双击防重复提交、刷新后恢复未答完的题、没有会吓到孩子的 `alert` 弹窗。
- **声音可以调**：中文语音朗读、语速、音量、音色、自动朗读、音效和背景氛围音都能在设置里调整，也可以一键静音。
- **离线也能玩**：完全不配置 AI 时，页面依然可以打开并持续做本地科学题。

## 快速开始

### 方式一：不配置 AI（最简单，离线可玩）

直接双击 `index.html`，或在项目目录启动任意静态服务器：

```bash
python -m http.server 8000
```

然后打开 <http://localhost:8000>。

这种方式只使用内置星际题库，不会发送任何内容到外部服务，适合先体验页面、语音和错题本。

> 如果项目目录里已经有填过 Key 的 `config.js`，页面会自动进入本机直连模式。想要完全离线，请先删除或清空 `config.js`。

### 方式二：本机测试 AI（Key 只在本地）

1. 复制配置模板：

   ```bash
   cp config.example.js config.js
   ```

2. 在 `config.js` 中填入自己的 DeepSeek API Key。
3. 用 `python -m http.server 8000`（或直接双击 `index.html`）启动后打开页面。请只在本人电脑上测试，不要用这种方式给局域网里的其他设备访问。

> `config.js` 已被 `.gitignore` 忽略。**不要把真实 Key 写进 `index.html`、`app.js`、`README.md` 或任何会提交的文件。**
>
> 直接把 Key 放在浏览器里，任何能打开页面的人都能在网络请求里看到它。这种方式只适合自己电脑上的临时测试。
>
> `server.js` 会始终拒绝把 `config.js` / `config.local.js` 作为静态文件返回，即使没有设置环境变量 Key 也一样；这样能避免把本机 Key 误发给同一网络里的其他设备。通过 `server.js` 部署时请使用方式三。

### 方式三：学校 / 公开部署（推荐，使用服务端代理）

项目自带零依赖的 `server.js`，同时做静态文件服务器和 DeepSeek 代理。Key 只存在服务器环境变量里，不会发到浏览器。

```bash
# Git Bash / macOS / Linux
DEEPSEEK_API_KEY="sk-你的Key" PORT=8000 node server.js
```

```powershell
# Windows PowerShell
$env:DEEPSEEK_API_KEY="sk-你的Key"
$env:PORT="8000"
node server.js
```

打开 <http://localhost:8000>。同一局域网内的其他设备可通过 `http://老师电脑的IP:8000` 访问。

服务启动时会打印当前模式，但不会打印 Key：

```text
[spacepet] listening on http://0.0.0.0:8000 — AI 代理已启用
```

没有设置 `DEEPSEEK_API_KEY` 时，服务会正常运行静态页面，前端自动退回本地题库。

## 服务端配置

`server.js` 只使用 Node.js 内置模块，不需要 `npm install`。需要 Node.js 18 或更新版本。

| 环境变量 | 默认值 | 说明 |
| --- | --- | --- |
| `DEEPSEEK_API_KEY` | 空 | 服务端 Key；为空时关闭 AI 代理，只用本地题库 |
| `DEEPSEEK_MODEL` | `deepseek-chat` | 使用的模型 |
| `DEEPSEEK_API_URL` | `https://api.deepseek.com/chat/completions` | 上游接口地址 |
| `HOST` | `0.0.0.0` | 监听地址；只给本机用可设为 `127.0.0.1` |
| `PORT` | `8000` | 端口 |
| `UPSTREAM_TIMEOUT_MS` | `18000` | 等待 AI 的最长时间 |
| `RATE_LIMIT_PER_MIN` | `60` | 每个浏览器会话每分钟最多请求数 |
| `IP_RATE_LIMIT_PER_MIN` | `500` | 每个 IP 每分钟最多请求数（兼容学校共享出口） |
| `MAX_CONCURRENT` | `80` | 同时发往 AI 的最大请求数 |
| `TRUST_PROXY` | `0` | 部署在反向代理后面时设为 `1`，才会读取 `X-Forwarded-For` |

其他保护：

- 请求体上限 64 KB，消息条数和长度都有上限。
- 上游超时、空回复、非 2xx 都会转成孩子能理解的状态，并让前端安全退回本地题库。
- 代理始终拒绝把 `config.js`、`config.local.js`、`server.js` 和隐藏文件当静态资源返回，避免本机 Key 被同网络的其他设备下载。
- 返回 `Content-Security-Policy`、`X-Content-Type-Options`、`Referrer-Policy` 等安全响应头。
- 不记录孩子的消息内容，也不记录 Key。

### 部署到公网时

单台 Node 进程适合一个班级、一个学校或小规模使用。面向几千到几万名学生时，需要正常的线上部署：

1. 用 Nginx / Caddy 等反向代理终止 HTTPS，并设置 `TRUST_PROXY=1`。
2. 运行多个 `server.js` 实例，或在入口层做限流；当前进程内限流无法跨实例共享。
3. 将静态文件交给 CDN，把 `/api/chat` 转发到代理实例。**上传静态文件时不要带上 `config.js` / `config.local.js`**，即使文件已被 `.gitignore` 忽略，手动上传整个文件夹仍可能把它带上去。
4. 监控 DeepSeek 配额、429 和超时；前端已有自动降级和冷却，但容量规划仍要按真实并发估算。
5. 学生档案目前保存在各自浏览器的 `localStorage` 中。若需要跨设备同步、班级管理或教师后台，需要另外接入带账号体系的后端；本项目没有把本地档案伪装成云端账号。

## 学生档案、每日进度与错题本

### 档案

- 进入页面必须填写名字或小名，并选择年级（1–2、3–4、5–6 对应低/中/高年级提示）。
- 最近使用列表最多显示 50 位同学；列表只用于快速填入名字，不会自动替孩子进入。
- 在设置中可以“换同学”，回到欢迎页。
- 每人的数据分别存在 `localStorage` 的 `dudu_v3_data::<学号>` 下；旧版本的 `dudu_student_name` / `dudu_wrong_book` 会在名字匹配时迁移。

### 每日状态

- 每天第一次进入会更新连续天数、今日题数和今日星星。
- 日期变化后，今日计数和待答状态会重置，但总星星、等级、错题本和历史记录保留。
- 刷新页面时，如果上一道题是两小时内且同一天的未完成题，会恢复题目和已试选项，不会重复加题数或星星。

### 错题本规则

- 答错后自动加入；同一道题再次答错只增加错误次数，不会堆出重复卡片。
- 支持“全部 / 待复习 / 已掌握”和按学科筛选；学科多于一个时自动分组，并显示每组题数。
- 点击“重新作答”会在错题本内原地练习，选项会重新打乱。
- 练习时第一次答错可以再试；第二次答错会显示正确答案和解释；可以“再练一次”。
- 每成功答对一次，卡片上的三个进度点亮起一个。**累计答对 3 次后**，“移出错题本”按钮才会启用；项目不会自动删除错题，删除权交给孩子。
- 已掌握但还没删除的题会进入“已掌握”筛选，仍可点“再复习”。
- 旧版本迁移过来、缺少选项数据的题目会被标记为旧记录，可以直接删除，但无法练习。
- 删除是两次确认；批量“清理已掌握”也有两步确认，避免误触。

## 语音与音效

- 使用浏览器 Web Speech API，优先选择中文女声/自然音色；没有中文音色时会给出提示。
- 支持自动朗读、手动重播嘟嘟的每句话、语速 0.8–1.2、音量调节和音色选择。
- 朗读前会去掉 emoji、Markdown 符号和不适合作答朗读的格式。
- 音效由 Web Audio API 实时合成，不依赖外部音频文件；可单独关闭。
- 背景氛围音默认关闭，打开后音量很低；静音会同时停止朗读、音效和氛围音。
- 浏览器通常要求用户先点一下页面才允许播放声音，所以第一次交互后才会启用音频。

## 安全与儿童隐私

- 所有由 AI 或孩子产生的文字都通过 `textContent` / DOM 节点渲染，不用不可信 `innerHTML`，避免脚本注入。
- 聊天先经过本地安全过滤，再决定是否请求 AI；涉及自伤、色情、暴力、毒品、赌博、隐私索取等内容会转到固定的温和回复，或建议告诉家长/老师。
- AI 出题会校验 JSON、选项数量、唯一正确答案和危险内容；不合格就丢弃并改用本地题。
- 提示词要求不索要住址、电话、学校、密码等个人信息，不进行医疗诊断，不讨论政治敏感内容。
- 名字只保存在本机，不会出现在给 AI 的提问或聊天上下文里；嘟嘟统一用“你”称呼孩子。
- 使用 AI 时，聊天内容和题目上下文会发送给 DeepSeek。学校部署应在隐私说明中告知家长和老师。
- 不要把真实 Key 提交到 Git。若 Key 曾经出现在提交记录、公开仓库或聊天记录中，请立即到 DeepSeek 控制台删除并重新生成。

## 项目结构

```text
SpacePet/
├── index.html          # 页面结构、欢迎页、错题本/设置/聊天弹层
├── styles.css          # 太空主题视觉、响应式布局、动效与无障碍样式
├── knowledge.js        # 本地无限题库：五个学科、随机生成、每日主题、聊天兜底
├── app.js              # 学生档案、答题流程、错题本、语音、音效、AI 与界面逻辑
├── server.js           # 零依赖静态服务器 + DeepSeek 代理（生产推荐）
├── config.example.js   # 本机直连 Key 的配置模板（公开部署不要用）
├── config.js           # 本机 Key（已 gitignore，不提交）
├── README.md
└── .gitignore
```

## 本地检查

```bash
node --check app.js
node --check knowledge.js
node --check server.js
node server.js
```

然后访问 <http://localhost:8000>，至少检查：

1. 第一次进入必须填名字、选年级。
2. 连续答题，答对/答错都有即时反馈；第二次答错能看到解释。
3. 答错后打开错题本，重做同一道题，累计答对 3 次后删除按钮才可用。
4. 刷新页面，未答完的题和星星没有被重复计算。
5. 设置里切换同学，旧聊天和旧题不会串到新同学。
6. 关闭网络或清空 Key，页面仍能从本地题库继续出题。
7. 手机宽度下按钮可点、文字不溢出，弹层可以关闭。

## 浏览器兼容性

- Chrome / Edge：推荐，中文语音和全部功能最完整。
- Safari：页面和语音可用，音色与 Windows 不同。
- Firefox：语音取决于系统是否安装中文语音包。
- 需要支持 ES6、`fetch`、`localStorage`、Web Speech API（可选）和 Web Audio API（可选）。不支持 IE。
