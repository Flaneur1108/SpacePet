# SpacePet · 星际宠物嘟嘟

面向乡村留守儿童的 AI 外星宠物科普网页。孩子唤醒来自外星的宠物「嘟嘟」并给它起名字，嘟嘟每次分享自己在人类家庭和地球上的新发现，用提问和猜谜的方式，陪孩子一起认识物理、化学、生物、天文和地理。

## 项目背景

乡村留守儿童往往缺少持续的陪伴和高质量的科普引导。SpacePet 把「会说话的小伙伴」和「科学小问答」结合在一起：

- **陪伴感**：嘟嘟不是问答机器人，而是一个寄宿在好朋友家、每天自己出门探索的外星宠物。它用「你」来称呼孩子，不叫「主人」、不反复喊名字，努力像一个真正的朋友。
- **科普性**：每次游戏最多 10 个科学分享，覆盖物理、化学、生物、天文、地理五个学科，由模型随机选择主题，避免变成单一的物理题。
- **低门槛**：单个 HTML 文件即可运行，不需要安装 App，浏览器打开就能玩；支持中文语音朗读，降低识字量不足的孩子的使用门槛。
- **可持续**：答错的题目进入「嘟嘟的错题本」，方便复习；名字和错题保存在本地，不上传服务器。

## 玩法

1. **唤醒与起名**：打开页面点击「点击唤醒星际宠物」，首次使用时输入自己的名字，嘟嘟会记住这位好朋友。
2. **科学分享**：界面显示「今日分享 n/10」，每次游戏最多 10 关。每一关嘟嘟先讲一段自己的见闻，再提出一个三选一的问题。
3. **答题与亲密度**：答对后亲密度进度条增长、进入下一关；答错时重新给出选项，并把题目记入错题本，可以再试一次。
4. **神奇小拓展**：答对后还有一个「猜猜看」小实验问题，揭晓答案并鼓励孩子自己动手观察。
5. **错题本**：点击右上角「📕 错题本」随时查看错题、正确答案和嘟嘟的解析。
6. **自由聊天**：完成 10 个分享后，底部会解锁聊天输入框，可以自由和嘟嘟聊天。
7. **重置**：右上角「🔄 重置」清空名字、错题和进度，重新开始。
8. **语音朗读**：嘟嘟说的话会用浏览器语音合成朗读，并自动过滤 emoji 和语气词。

## 技术栈

| 技术 | 说明 |
| --- | --- |
| 原生 HTML / CSS / JavaScript | 无框架、无构建步骤，页面与全部业务逻辑都在 `index.html` 中 |
| [DeepSeek Chat API](https://api.deepseek.com) | 通过 `fetch` 调用 `deepseek-chat` 模型，生成每日分享、题目和自由对话 |
| Web Speech API (`speechSynthesis`) | 中文 TTS 朗读，优先选择 Xiaoxiao / Yunxi 等中文音色 |
| localStorage | 保存孩子名字和错题本（键：`dudu_student_name`、`dudu_wrong_book`） |
| CSS Animations | 宠物悬浮、眨眼、气泡弹出、按钮脉冲等动效 |

### 实现要点

- **Prompt 契约**：系统提示词要求模型严格返回单行 JSON（场景、题干、三个选项、正确答案、反馈、解析、拓展题），前端解析后渲染。解析失败时使用内置的「星星为什么会眨眼」兜底题目，保证网络异常时仍可玩。
- **角色语气约束**：Prompt 约束 + 前端双重过滤「哈哈」「主人」等词，避免模型出戏或使用不当称呼。
- **防幻觉处理**：拼接场景时剔除「帮你」「看你」等不符合「嘟嘟自述」视角的表达。
- **学科随机**：在 Prompt 中要求从物理、化学、生物、天文、地理中随机选科，保证内容广度。
- **语音过滤**：朗读前移除 Emoji 和语气词，并把「💡【嘟嘟的神奇小拓展】」替换成适合朗读的口语表达。
- **兜底策略**：`callAI` 捕获网络异常返回「网络故障。」，配合兜底题目保证页面不会卡死。

## 快速开始

1. 准备一个 DeepSeek API Key（在 [DeepSeek 开放平台](https://platform.deepseek.com) 申请）。
2. 复制示例配置并填入 Key：

   ```bash
   cp config.example.js config.js
   ```

   ```js
   // config.js
   window.DUDU_CONFIG = {
       DEEPSEEK_API_KEY: "sk-你的Key"
   };
   ```

3. 打开页面：
   - 直接双击 `index.html`；或
   - 推荐用本地服务器（避免部分浏览器的跨域限制）：

     ```bash
     python -m http.server 8000
     ```

     然后访问 <http://localhost:8000>。

4. 建议使用 Chrome / Edge，中文语音合成效果最好；使用过程需要联网。

## 安全与隐私

- **API Key 不进仓库**：Key 只保存在 `config.js` 中，该文件已被 `.gitignore` 忽略。请勿把 Key 写回 `index.html` 或任何会被提交的文件。
- **纯前端的固有限制**：页面在浏览器里直接调用 DeepSeek，任何能打开页面的人都能在网络请求中看到 Key。**如果要公开部署，请改用后端或 Serverless 函数代理请求**，不要把 Key 放在公开的前端代码里。
- **Key 一旦泄露立即轮换**：如果 Key 曾经出现在提交记录、公开仓库或聊天记录中，请到 DeepSeek 控制台删除并重新生成。
- **儿童隐私**：孩子输入的名字和错题本只保存在本机 `localStorage`，不会上传；但对话内容会发送给 DeepSeek 用于生成回复。面向儿童使用时，建议由家长或老师告知并监护。
- **部署提示**：若使用 GitHub Pages 等静态托管，`config.js` 不会随仓库发布，需要通过部署流程单独注入——这同样会把 Key 暴露给访问者，因此仍建议使用代理。

## 浏览器兼容性

- Chrome / Edge（推荐）：fetch、中文语音合成都正常。
- Safari：语音合成可用，音色与 Windows 不同。
- Firefox：语音合成依赖系统语音包，可能没有中文音色。
- 需要支持 ES6、`fetch`、`localStorage`，不支持 IE。
